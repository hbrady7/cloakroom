# CLOAKROOM

Free politician + insider trade intelligence. Congressional STOCK Act disclosures and
SEC Form 4 insider filings, scored by a deterministic signal engine, briefed daily by
Claude, published as a static site. Total marginal cost: $0.

> Research only. Nothing here is investment advice. See `/methodology` on the site.

**Status: scaffolding.** Full docs land in Phase 6.

- `/web` — Next.js 15 dashboard (Vercel Hobby, static generation)
- `/pipeline` — Python 3.12 fetchers + signal engine (runs in GitHub Actions only)
- `/data` — committed JSON outputs (the "database")
